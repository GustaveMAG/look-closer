# Look Closer — Artthropic

« L'œuvre qui te regarde aussi » : au musée, le visiteur scanne un QR code avec son téléphone (sans appli), l'œuvre lui parle et lui pose des questions qui l'obligent à regarder les détails.

- `index.html` : l'expérience visiteur, plein écran sur téléphone.
- `presenter.html` : la version à projeter pendant le pitch (téléphone + 5 étapes).
- `qr-code.png` : QR code vers le site.

Site statique (HTML/CSS/JS), sans compte ni collecte de données. Le tableau « Hiver au village » est une œuvre fictive dessinée en code.
